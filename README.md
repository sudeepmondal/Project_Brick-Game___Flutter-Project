# Brick Game – Flutter Project

This repository contains a **Brick Game** developed using **Flutter**.  
The project is built as a simple game development practice project and can be used for learning Flutter, Dart, and basic mobile game logic.

## Project Overview

The main objective of this project is to create a brick-style game using Flutter.  
The project demonstrates Flutter UI design, game screen structure, user interaction, and basic game development concepts.

## Key Features

- Brick game concept built with Flutter
- Simple and lightweight project structure
- Organized Flutter project folder
- Beginner-friendly game development example
- Easy to customize and improve
- Suitable for portfolio and practice purposes
- Can be extended with scoring, levels, animations, and sound effects

## How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/sudeepmondal/Project_Brick-Game__Flutter-Project.git
```

2. Go to the project directory:

```bash
cd Project_Brick-Game__Flutter-Project/brick_game
```

3. Get Flutter dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```

## Build Commands

For Android APK:

```bash
flutter build apk
```

For Web, if web support is enabled:

```bash
flutter build web
```

For Windows, if Windows support is enabled:

```bash
flutter build windows
```
