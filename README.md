# Smartphone Addiction Survey Image Data Collector App – Flutter Project

This repository contains a **Smartphone Addiction Survey Image Data Collector App** developed using **Flutter**.  
The project is designed to collect survey-related image data for smartphone addiction analysis, research, or academic data collection purposes.

## Project Overview

The main objective of this project is to build a simple and useful Flutter application that can support image-based survey data collection.  
This app can be used for collecting user responses, images, and related information for smartphone addiction research or dataset preparation.

## Key Features

- Flutter-based mobile application
- Image data collection support
- Survey-oriented app structure
- Simple and user-friendly interface
- Organized source code inside the `lib/` folder
- APK file included for easy installation or testing
- Suitable for research, academic, and data collection projects

## How to Run the Project

1. Download or clone this repository:

```bash
git clone https://github.com/sudeepmondal/Smartphone-Addiction-Survey-Image-Data-Collector-App__Flutter-Project.git
```

2. Go to the project directory:

```bash
cd Smartphone-Addiction-Survey-Image-Data-Collector-App__Flutter-Project
```

3. Get Flutter dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```

## APK Installation

If an APK file is available inside the `flutter-apk/` folder, you can install it directly on an Android device for testing.

Steps:

1. Download the APK file from the `flutter-apk/` folder.
2. Transfer it to your Android phone.
3. Enable installation from unknown sources if required.
4. Install and open the app.
